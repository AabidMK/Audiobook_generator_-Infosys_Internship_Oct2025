# 🎧 AI Audiobook Generator

Transform any document into professional-quality audiobooks using AI-powered text enhancement and intelligent document-based Q&A.



## ✨ Features

📁 Multi-Format Support
Upload and process TXT, PDF, DOCX, and Images (JPG/PNG)

🤖 AI-Powered Enhancement
Convert raw text into engaging audiobook-style narration

🎵 Professional Audio Output
Multiple voices and speed controls using Edge-TTS

💬 Intelligent Q&A (RAG-based)
Ask questions and get accurate answers from your uploaded documents

💾 Vector Database Integration
Efficient storage and retrieval using Qdrant

🎨 Modern UI
Glassmorphism-inspired interface with smooth animations

## 📖 How to Use

1.Upload Document
Drag and drop any supported document or image

2.Configure Settings
Select voice, narration speed, and AI models from the sidebar

3.Generate Audiobook
Click “Start Processing” to create the audiobook

4.Ask Questions
Use the Q&A tab to query your document intelligently
